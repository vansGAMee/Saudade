# Security Policy

## Supported Versions

Saudade is currently in active pre-alpha development. Security patches are provided on the latest `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Saudade, please do not open a public issue.

Instead, please report security vulnerabilities using **GitHub Private Vulnerability Reporting** via the repository's **Security > Advisory** tab:

https://github.com/vansGAMee/Saudade/security/advisories/new

If private vulnerability reporting is unavailable, please open an issue with minimal non-exploitative reproduction details or contact the repository owner directly through GitHub.
